# Excel-Sales-Dashboard
An interactive and dynamic data visualization dashboard built completely in Microsoft Excel to track key performance indicators (KPIs) and drive data-informed decisions. It transforms raw data into a clean, intuitive, and executive-ready interface. Users can dynamically filter information to explore trends and review metrics in real time.
